This MIDI keyboard is meant to be a toy keyboard that will allow me to play most kinds of music.

The design of this is based off a basic keyboard, there are 8 keys for each of the 7 notes of an ionian scale with an extra tonic at the top
The aim is meant to be c-c with ionian in between but that can be programmed in firmware later

There is going to be a pitch bender and or modulation with the 2 dimensional joystick and octave jump up and down with instrument change and volume.

The chance to have a pitch bend with the joystick allows me to play more complex jazz tracks similar to the blues harmonica.
